# Lexicon · IELTS & GRE 词境（高阶词汇与语料关系图谱学习系统）

一款采用 **Apple Human Interface (macOS Sequoia / iOS 18 Liquid Glass)** 视觉美学设计的离线词汇与语料关系图谱工作台。同时提供 **轻量多文件模块化版本 (`index.html`)** 与 **单文件便携版本 (`lexicon-studio.html`)**，均支持本地双击直接运行或通过 GitHub Pages 部署。

## 核心特性

1. **三大零重合核心词库（共 10,200 词条 · 100% 互斥）**
   - **雅思核心 7000 (`IELTS Core 7000`)**：`7,020` 词，按自然与环境、社会与经济、健康与生活、科技与教育、文化与历史、逻辑与论证等高频场景分类。
   - **雅思写作 Band 8+ (`IELTS Writing Advanced`)**：`159` 个高浓缩、高泛用性、零同义冗余的大作文核心议论词，按改善与恶化、因果与影响、让步转折、利弊权衡、观点评价、数量与趋势等写作功能分类。
   - **GRE 核心进阶 (`GRE Verbal Master`)**：`3,021` 词，聚焦六选二（Sentence Equivalence）、填空高频逻辑词与学术阅读难词。

2. **精准语义辨析与高频搭配词伙网络（34,000+ 经过词典与语义核验的真实连接）**
   - **近义辨析 (`synonyms`) & 反义对照 (`antonyms`)**：严格按同词性、同义项核验，彻底剔除强行凑数的无关联词；无真实反义词的具体名词不强行编造反义词。
   - **常用搭配词伙 (`partners`)**：每个词条内置 1–2 个在词库内双向连通的真实搭配词（标注 **`动+名`**、**`形+名`**、**`名+名`**、**`副+动`**、**`副+形`**、**`动+形`** 及具体短语），在词卡、详情抽屉、3D 闪卡与关系图谱中均可一键点击跳转。
   - 每个词条内置 **地道搭配 (`collocations`)**、**带精准高亮的 IELTS/GRE 学术例句 (`examples`)**，以及 **三段式结构化深度用法指南 (`note`)**。

3. **高效背词与交互体验**
   - **卡片网格 / 沉浸式 3D 闪卡 / 语义与搭配图谱** 三大模式自由切换。
   - **一键乱序背单词**：支持卡片列表乱序洗牌与闪卡随机抽背。
   - **智能页码与词卡直达**：支持输入页码（如 `12`）、词卡序号（如 `#256`）或中英文关键词直达目标词卡并高亮定位。
   - **免进详情快捷标记与屏蔽已掌握**：在列表卡片或闪卡正面即可直接标记「待复习 / 已掌握」，并支持一键「屏蔽已掌握」词汇。
   - **JSON / CSV 词库导入导出与 AI 提示词工坊**：所有学习进度自动持久化保存在浏览器本地 `localStorage`。

## 目录结构与使用方式

- **方式一：多文件模块化版本（推荐，入口轻量、结构清晰）**
  - 直接双击打开 [`index.html`](./index.html)（仅 ~1 KB），或部署至 GitHub Pages / 静态服务器：
    - `assets/styles.css`：Apple 毛玻璃主题与响应式布局样式
    - `assets/fonts.css`：离线内嵌字体样式
    - `assets/lexicon-io.js`：词库导入导出与校验引擎
    - `assets/vendor.js`：React 18 + 图标与压缩运行时
    - `assets/app.js`：核心交互组件与状态逻辑
    - `data/`：按词库拆分的模块化数据分片（`lexicon-writing.js/.json`、`lexicon-ielts-1.js`、`lexicon-ielts-2.js`、`lexicon-ielts.json`、`lexicon-gre.js/.json`）
- **方式二：单文件全内联便携版**
  - 直接双击打开 [`lexicon-studio.html`](./lexicon-studio.html) 即可单文件离线使用全部功能。
